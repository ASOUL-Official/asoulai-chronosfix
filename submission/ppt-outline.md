# ChronosFix 初赛 PPT 大纲

## 1. 封面

ChronosFix：软件故障时间机器  
方向三：软件研发全流程协同  
队伍：AsoulAI  
副标题：让每次事故沉淀为可复用 Skill、故障基因包和可审计证据护照。

## 2. 痛点：AI 猜根因不等于研发协同

- 线上故障涉及代码、配置、依赖、流量、CI、工单、发布审批。
- 现有 AI 工具常停留在日志总结和经验猜测。
- 研发真正需要的是：可证明根因、可验证补丁、可审计发布、可复用经验。

## 3. 方案一句话

ChronosFix 用多 Agent 重建故障时间线，在平行版本中做反事实实验，再通过缺陷基因变体测试补丁，最终输出带证据护照的修复方案。

## 4. 官方参考 Baseline 对照

- 官方规范未提供必须继承的代码仓库型 baseline，但给出了 OpsPilot Zero 作品示例 Demo。
- ChronosFix 对齐官方示例的 AgentTeams、7 职能 Agent、Skill 工程化、MCP/适配器、Trace、审计和 Mock Demo 边界。
- ChronosFix 的增强：从运维自愈迁移到软件研发全流程协同，新增故障时间机器、缺陷基因实验室、证据护照和研发质量资产飞轮。

## 5. 多 Agent 协作架构

- Incident Commander：任务拆解、状态流转、人工升级。
- Timeline Analyst：融合 Git、日志、Trace、配置、流量与告警。
- Hypothesis Scientist：生成可证伪根因假设。
- Universe Builder：构建反事实平行宇宙与缺陷基因变体。
- Patch Engineer：生成补丁候选和回滚契约。
- Adversarial Verifier：补丁竞赛与对抗验证。
- Release Auditor：风险门禁、证据护照和审计报告。

## 6. 创新一：故障时间机器

- 不让 AI 直接猜，而是重放事故。
- 对每个可疑变更执行“撤销—重放—对比”。
- 用失败率和 P99 变化判断主因、放大因素、伪相关。

## 7. 创新二：缺陷基因实验室

- 从一个已证明事故繁殖 8 个同源变体。
- 覆盖高流量、下游变慢、组合压力、容量临界、恢复尖峰、隐性配置漂移。
- 补丁必须在故障家族中通过竞赛，而不是只修原始样例。

## 8. 创新三：证据护照

- 补丁必须携带需求声明、因果声明、验证声明、风险声明、回滚声明、缺口声明。
- 没有证据护照，不进入发布审批。
- 让自动修复从“AI 建议”变成“可进入 PR/变更单的证明材料”。

## 9. 创新四：Skill 自进化工坊

- 一次事故结束后，自动蒸馏出可复用 Skill 候选。
- 示例：连接池容量守卫、反事实配置回放、带证明补丁生成器。
- 形成“事故变资产”的组织学习闭环。

## 10. 创新五：研发质量资产交易所

- 把事故处理过程沉淀为故障基因包、证据护照模板和可评测 Skill。
- 企业内部可跨团队复用，云厂商可作为 AIOps / CI/CD / 配置中心 / 工单平台增值模块。
- 商业模式包括团队版 SaaS、企业私有化、云市场插件、故障基因包 / Skill 市场和审计合规模块。
- 护城河来自持续积累的反事实事故数据、补丁验证结果和可复用质量资产库。

## 11. Demo 场景

- 订单创建接口午间高失败率与长尾延迟。
- 可疑因素：关联日志代码变更、支付客户端升级、连接池缩容。
- 反事实实验结果：连接池缩容为主因，依赖升级为放大因素，代码变更被证伪。

## 12. 运行结果

- 基线失败率：48.72%，P99：606.96 ms。
- 根因假设：3 个。
- 补丁候选：4 个。
- 故障基因变体：8 个。
- 选中补丁：恢复连接池 24 并增加容量验证门禁。
- 证据护照：12 条声明。
- Trace Span：15 段。
- Repair Cockpit：用交互页面展示时间线、平行宇宙、缺陷基因、补丁竞赛和证据护照。

## 13. 安全与审计

- 中高风险补丁必须人工审批。
- 每个补丁带回滚策略。
- 每次 Agent/Skill 调用写入 Trace。
- 报告不包含密钥或原始敏感数据。

## 14. AgentTeams / MCP 落地路线

- 初赛：本地可运行 Demo + AgentTeams 编排草案。
- 复赛：接入真实 Git、CI、日志、Trace、配置中心、工单系统。
- 生态：开放 Skill 规格、MCP Schema、样例故障和评测脚本。

## 15. 总结

ChronosFix 的目标不是替代研发判断，而是把研发判断所需的证据变成可复利的质量资产：让根因可证明，让补丁可验证，让发布可审计，让经验可复用，让事故复盘可以商业化分发。
